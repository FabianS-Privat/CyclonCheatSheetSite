## Zone Read

Piety and the Trial of Ascendancy can be seen in the Fog, while still undiscovered.

| Piety Undiscovered                                                | Trial Undiscovered                                                |
| ----------------------------------------------------------------- | ----------------------------------------------------------------- |
| ![Piety Undiscovered](./img/Crematorium/Piety%20Undiscovered.png) | ![Trial Undiscovered](./img/Crematorium/Trial%20Undiscovered.png) |

To differentiate between the Diffrent Main Layout Variants, we always check West first. If West is a Dead End, we are in the East Variant. If we instead can move South directly, we are in the South Variant.

If we find the Trial West but Below the Entrance on the Minimap, Piety will be East. IF the Room leading to the Trial was a Linear one, Piety is South East.
If the Path to the Trial was through several small Rooms, Piety will be in the North-East Corner.

If it is an East Layout, move North above the Waypoint to find the Trial. If it is at the East Edge of the Zone, Piety will be West of the Trial, otherwise Piety will be East of the Trial.

If the Layout is a West Variant. continue West to see any Identifiers of Piety or the Trial, move to find the Trial. The Book Icon always indicates the Entrance to the Trial.
Based on the Trial postion, we can pinpoint Pietys Position. See West Extending Zone Image 1-3.

## Zone Read

:::tip Simple Read
Follow the Red Carpet
:::

If the first door is facing South, the Exit is in the North-East Corner.
If the first door is facing North, the Exit is in the North-West Corner.

In the Big Room with the several Rows of Banks, the Carpet is forking of in the correct Direction. Left for North-East Exit and Right for North-West Exit.

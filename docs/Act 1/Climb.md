## Zone Read

:::tip Simple Read

Follow the Left Wall from the Entrance. Detailed Example seen in Image 6.

:::

There are always 5 Slopes / Ledges you have to take before you will reach the Lower Prison Entrance. The Legion Monolith is always before the last 2. Following the Direction the Zone opens, while orienting yourself along the Left Edge of the Zone.
If the first Ledge has a C shaped Hook, like in Image 3 or 4, the Exit will be in a Straigth line from that Hook.

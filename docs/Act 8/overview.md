| Underbelly        | Place Portal at the T Section                  |                                                                        |

| Underbelly        | Get to Bath House                              |                                                                        |
| Bath House        | Place Portal and get to Lunaris Concourse      |                                                                        |
| Lunaris Concourse | Get to WP and go to Town                       |                                                                        |
